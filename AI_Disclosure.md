## Our team used Claude and Google Gemini as AI coding assistants throughout the project. These tools were used to help explain modelling approaches, troubleshoot, and improve Python code, suggest feature engineering techniques, and assist with the implementation of models such as LightGBM and XGBoost. All generated code and suggestions were reviewed, modified where necessary, and run by the team. 

## We also consulted external online resources for background information about the Beijing air-quality monitoring stations, including station locations, maps, and contextual information about the monitoring sites.

## No external datasets were added to the competition dataset, and no pretrained machine-learning models were used. The final predictions were generated using the competition-provided training and test data.
